# jeu-m-lange-de-mots

Jeu de **mots mélangés** à deviner, développé en HTML5, CSS3 et JavaScript.

> 🚧 Projet **en cours de développement** — le code source sera bientôt disponible dans ce dépôt.

## Concept

Retrouve le mot correct à partir d'un mot dont les lettres ont été mélangées. Le jeu propose plusieurs mots et niveaux de difficulté.

## Prévu

- Sélection de difficulté
- Indices disponibles si le joueur est bloqué
- Interface responsive, jouable sur mobile
- Suivi du score et du temps

## Stack

- HTML5 / CSS3
- JavaScript (vanilla)

## Roadmap

- [ ] Logique de mélange et de vérification des mots
- [ ] Interface de jeu et niveaux
- [ ] Indices et scores
